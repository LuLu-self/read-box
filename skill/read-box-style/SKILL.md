# Read Box 介面風格

LuLu 的個人文章收藏網站 Read Box 的視覺語言。骨架來自 GitHub Box（淡方格紙、粗線框卡片、膠囊按鈕），配色來自 Threads 的黑白分類按鈕，加上淡藍底、超粗黑標題與橘色重點。動作按鈕用橄欖綠。

做網頁、Artifact、卡片列表、儀表板或手機介面時，照這份做。完整 CSS 在 `references/tokens.css`，可以整段貼進 `<style>`；元件寫法與範例在 `references/components.md`；`examples/sample.html` 是一頁完整示範。

## 什麼時候用

- LuLu 說「用 Read Box 風格」「跟 Read Box 一樣」「淡藍加橘色那個風格」
- 做給 LuLu 自己看的網頁、Artifact、清單、卡片介面，而她沒有指定別的風格

LuLu 指名其他主題（例如 lulu-slide-themes 的暖色 keynote、包豪斯、瑞士 IKB、電光）時，用她指名的，不要套這份。

## 色彩（深色）

底 `#141414`、卡片 `#1f1f1f`、文字 `#f3f5f7`、次要 `#9aa7b1`、框線 `#d6d6d6`、淡框 `#30363b`、橘 `#ff7a45`（配黑字 `#141414`）、綠 `#a8cc78`（配黑字）、綠淡底 `#1d2616`、筆記紙 `#24221d`、紙膠帶 `#7a3f2a`。深色要另外設計過，不是直接反轉。

做法：淺色寫在 `:root`；深色寫兩次，一次在 `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) {…} }`，一次在 `:root[data-theme="dark"]`，讓「跟著手機／淺色／深色」三種選擇都正確。

## 顏色比例（LuLu 訂的規則，一定要守）

**底色 60%、黑 28%、橘約 8%、綠約 4%。**

- **橘色只用在「要你注意」**：未讀、該重讀了、標題裡最重要的一個數字或關鍵字、logo。一個畫面只出現幾處。
- **綠色只用在「可以按」**：主要按鈕（收進來、儲存）、地圖按鈕、「實踐過」狀態。
- 其他標籤一律用**黑底白字**或**白底灰框**，不要用橘色或綠色。
- 品牌色（YouTube 紅、FB 藍等）只能出現在 16px 小圖示上，文字和框維持黑白。

## 字體

- 字型：`"Noto Sans TC", system-ui, -apple-system, "PingFang TC", "Microsoft JhengHei", sans-serif`
- Google Fonts 載入：`https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@400;700;900&display=swap`
- 大標題、卡片標題、區塊標題：**900（超粗）**，`text-wrap: balance`
- 內文 15px、行高 1.6；次要說明 12–14px 用次要灰

## 形狀與線條

- 卡片：1.5px 墨黑框、圓角 14px、白底；**不要加陰影**
- 卡片左側色條（我的標記）：6px，讀過＝灰、有用＝黑、實踐過＝綠（卡片底變綠淡底）、封存＝淡灰＋透明度 0.7
- 膠囊按鈕：圓角 999px、1.5px 墨黑框；選中＝**墨黑底、淺色字**（Threads 風）
- 次一層的膠囊：淡框 `#d2dfe9`，選中時改 2px 墨黑框、白底
- 主要按鈕：高 44px、圓角 12px、2px 框；動作按鈕用綠底
- 區塊標題底線：**一般直線**，2px 墨黑。**不要手繪線、波浪線**（LuLu 明確不要）
- 筆記紙區塊：橫線筆記紙＋左上一條斜貼的紙膠帶，用來放原文、摘錄

## 版面

- 手機優先：單欄、最大寬 760px、左右至少 16px（寫成 `max(16px, env(safe-area-inset-left, 0px))`）
- 分類列：膠囊橫向滑動，不換行；第二層（次分類、地區）在選了第一層之後才出現
- 進階條件收進「篩選」按鈕，選中的條件用可刪除的小膠囊（文字＋ ✕）顯示
- 頁面不能左右捲動

## 不要做的事

- 不要用奶油色＋襯線字＋赤陶色、紫藍漸層、到處都是圓角陰影卡片
- 不要用 emoji 當區塊符號（地點的 📍 例外）
- 不要讓橘色、綠色超過上面的比例
- 不要手繪線、波浪底線
